SAPRI · APP EPP · PRIMERA VERSIÓN FUNCIONAL

ARCHIVOS
1) 01_SUPABASE_EPP.sql
2) epp-admin.html  -> administración
3) epp.html        -> trabajador / firma

ORDEN
1. Supabase > SQL Editor > New query.
2. Abrir 01_SUPABASE_EPP.sql, copiar todo y ejecutar.
3. En GitHub Pages subir epp-admin.html y epp.html en el mismo repositorio/carpeta.
4. Abrir epp-admin.html.
5. Ingresar con el usuario administrador de Supabase.
6. Crear una entrega, seleccionar trabajador, revisar correo, agregar EPP y generar enlace.
7. Copiar el enlace y abrirlo en otro navegador/celular.
8. El trabajador ingresa su correo SAPRI, revisa cantidades, agrega observaciones, firma y descarga PDF.
9. Administración conserva el registro y puede volver a generar el mismo comprobante desde los datos firmados.

MAESTRO
- Se usó el archivo: 2026-11-02 Colaborador.xlsx
- Se incluyeron solo colaboradores cuya División = SAPRI.
- Correos: nombre.apellido@sapri.cl.
- Excepción aplicada: Romero, Alvaro Martin -> martin.romero@sapri.cl.
- El correo es editable en administración antes de crear la entrega.

SEGURIDAD
- El trabajador no puede consultar la tabla completa.
- El acceso del trabajador requiere TOKEN ÚNICO + correo asignado.
- El administrador usa Supabase Auth y tabla epp_admins.
- Para habilitar a otro administrador, agregar su correo en public.epp_admins.
